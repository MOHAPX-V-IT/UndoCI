# Changelog

## 0.1.0 — 2026-09-30

- Python CLI: run, validate, demo, replay, schema, report and doctor.
- Managed process and Docker Compose drivers with preserved state across release changes.
- Preparation, upgrade, rollback and cleanup hooks.
- HTTP status and JSON Pointer assertions; typed response captures and dependencies.
- Repeat confirmations, ordered prefix search and dependency-aware scenario reduction.
- Offline HTML, JSON, Markdown, JUnit and config-pinned replay manifests.
- Four stdlib/SQLite demos and a two-image PostgreSQL integration fixture.
- Cross-platform test workflow, package builds, MIT license and bilingual documentation.

Early release. Production certification, concurrent workload generation, multi-service release
switching and broker-specific probes are outside this release's scope.
